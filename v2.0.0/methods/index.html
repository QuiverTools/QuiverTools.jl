QuiverTools.__chow_ring_monomial_grading — Function
__chow_ring__monomial_grading(M::QuiverModuliSpace, f)

Compute the "pseudodegree" of the monomial f in the Chow ring of the moduli space M passed.

This method is unsafe, as it does not consider the actual degree of the MPolyRingElem objects passed. Instead, it assumes that the Chow ring passed has variables $x_{i, j}$ as in the Chow ring paper.

QuiverTools.poincare_polynomial — Function
poincare_polynomial(M::QuiverModuliSpace)

Compute the Poincaré polynomial of the moduli space M.

If the quiver has oriented cycles the moduli space is in general not projective, and this computes the Poincaré polynomial of its cohomology with compact support instead. As the moduli space is smooth, Poincaré duality relates the two: in dimension $n$ the compactly supported one is $L^n P(1/L)$ for the ordinary one $P(L)$.

If there are properly semistable representations the stack is not a $\mathbb{G}_m$-gerbe over the moduli space, and its motive does not give the cohomology. If the moduli space is nonetheless smooth, its cohomology is its intersection cohomology, which is then computed by intersection_poincare_polynomial; this needs M.theta to be generic for the slope of M.d and stable representations to exist. Otherwise an error is thrown.

Input

  • M::QuiverModuliSpace: a moduli space of representations of a quiver.

Output

  • the Poincaré polynomial of the moduli space, with compact support if the quiver has oriented cycles.

Examples

A Kronecker quiver setup where M is the projective line:

julia> Q = kronecker_quiver(2);

julia> M = QuiverModuliSpace(Q, [1, 1]);

julia> poincare_polynomial(M)
L + 1

The Poincaré polynomial of our favourite 6-fold:

julia> Q = kronecker_quiver(3);

julia> M = QuiverModuliSpace(Q, [2, 3]);

julia> poincare_polynomial(M)
L^6 + L^5 + 3*L^4 + 3*L^3 + 3*L^2 + L + 1

For dimension vector [2, 2] there are properly semistable representations, but the moduli space is smooth, as it is $\mathbb{P}^5$, so its intersection cohomology is used:

julia> M = QuiverModuliSpace(kronecker_quiver(3), [2, 2]);

julia> poincare_polynomial(M)
L^5 + L^4 + L^3 + L^2 + L + 1

With one vertex, two loops and dimension vector [1] the moduli space is the affine plane, whose only compactly supported class sits in degree 4:

julia> M = QuiverModuliSpace(loop_quiver(2), [1], [0]);

julia> poincare_polynomial(M)
L^2

poincare_polynomial(Q::Quiver, d::AbstractVector{Int}, theta::AbstractVector{Int}=canonical_stability(Q, d), denom::Function=sum)

Compute the Poincaré polynomial of the moduli space of theta-semistable representations of Q with dimension vector d.

As for the method taking a QuiverModuliSpace, for a quiver with oriented cycles this is the Poincaré polynomial of the cohomology with compact support, and with properly semistable representations it is computed from intersection cohomology if the moduli space is smooth.

Input

  • Q::Quiver: a quiver.
  • d::AbstractVector{Int}: a dimension vector.
  • theta::AbstractVector{Int}: a stability parameter. Default is canonical_stability(Q, d).
  • denom::Function: the denominator of the slope. Default is sum.

Output

  • the Poincaré polynomial of the moduli space, with compact support if the quiver has oriented cycles.

Examples

The Poincaré polynomial of our favourite 6-fold:

julia> poincare_polynomial(kronecker_quiver(3), [2, 3])
L^6 + L^5 + 3*L^4 + 3*L^3 + 3*L^2 + L + 1

QuiverTools._universal_chern_generators — Function
_universal_chern_generators(M::QuiverModuliSpace)

Compute the universal Chern classes $c_j(U_i)$ that minimally generate the Chow ring chow_ring(M). Return triples (vertex, chern_degree, var_index) where var_index is the index of the generator in gens(CH).

The first Chern classes $c_1(U_i)$ satisfy linear relations (from the choice of linearization), so only a maximal linearly independent subset of them is kept; they are processed in vertex order, so that $c_1(U_1)$ is the first. All higher Chern classes are always kept. For internal use only.

QuiverTools.support_subquiver — Function
support_subquiver(Q::Quiver, d::AbstractVector{Int})

Restrict (Q, d) to the support of d: the full subquiver on the vertices where d is nonzero, together with d restricted to those vertices.

The moduli space M(Q, d) is isomorphic to M(support_subquiver(Q, d)...), since a zero entry dᵢ = 0 forces Vᵢ = 0 in every representation. Results that only hold for a full-support dimension vector (e.g. the Mukai index, see [MR4352662]) must therefore be computed on this restriction rather than on (Q, d) directly.

For internal use only.

QuiverTools.@oscar_stub — Macro
@oscar_stub f

Mark f as an Oscar-backed entry point. Until Oscar is loaded, calling f loads it on demand and re-dispatches to the concrete method the extension defines. Once loaded, that method (being more specific than this varargs catch-all) is hit directly, so the trigger only fires once. If Oscar is already loaded and still nothing matches, this errors instead of looping.
